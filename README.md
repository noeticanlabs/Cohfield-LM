# Cohfield-LM

Cohfield-LM is the development repository for a CohBit-native adaptive continuation language model.

The repository begins from the domain-neutral computational base extracted from the Infrastructure-Generated CohField Geometry v0.01-v0.10 experiments. The infrastructure system is treated as the experimental specialization that exposed the mechanism; its electrical equations are not assumed to be universal model laws.

## Current milestone

**CF-ACP-000 — CohField Adaptive Continuation Profile**

Status: **pre-canonical base extraction**.

The minimum model profile separates:

- complete domain State `Z`;
- fast-state role `X`;
- persistent local-condition role `Theta`;
- persistent relational-configuration role `Psi`;
- domain evolution `Phi`;
- experience adaptation `A`;
- observation profile `O`;
- continuation-response map `R`.

Optional derived enrichments include differential response, pullback geometry, finite trajectory geometry, and counterfactual recovery-margin evaluation.

None of those objects replace the canonical CohBit primitives. In particular, model preference or endogenous ranking does not imply verification, admissibility, authority, execution, or commitment.

## Repository direction

1. Freeze the domain-neutral mathematical profile.
2. Freeze `CF-ACP-IC-00`, the implementation contract.
3. Build a dependency-light Rust reference runtime.
4. Reproduce the infrastructure phenomena as a domain profile without infrastructure logic in the core.
5. Only then instantiate the same base over natural language.

## Non-goals of the base

The base does not define:

- token prediction;
- neural networks;
- embeddings;
- Transformer attention;
- graph conductance physics;
- a universal learning rule;
- a universal endogenous value function.

`Q_rm` from v0.10 is retained as an experimentally supported optional counterfactual profile pending the v0.11 robustness campaign.
