# CF-LM Teacher Bridge v0.05

## Status

**PASS — bounded experience-derived role discovery plus selective structural transfer**

Branch: `agent/cf-lm-teacher-bridge-v005`

v0.04 established selective held-out transfer when the experiment supplied the source and target role families. v0.05 removes those family arrays from the runtime mechanism.

The narrower question is:

> Can CF-LM derive the relevant role sets from visible relational experience, infer which discovered role points to which other role, preserve member correspondence, and still cross a withheld relation after the teacher is removed?

## Frozen visible curriculum

The teacher supplies isolated visible pair episodes for 64 epochs:

```text
A1 -> B1
A2 -> B2
A3 -> B3

A1 -> C1
A2 -> C2
A3 -> C3

R1 -> B1
R1 -> B2
R1 -> B3

R2 -> C1
R2 -> C2
R2 -> C3

B1 -> C1
B2 -> C2
```

The held-out relation is never taught:

```text
B3 -> C3
```

`R1` and `R2` are neutral surface symbols. The runtime is not told that one is a source-role anchor and the other is a target-role anchor. It receives only the same learned `Psi` relation matrix generated by pair exposure.

`C3` is visible independently through `A3 -> C3` and `R2 -> C3`, so v0.05 still tests relation transfer to a known target identity rather than invention of an unseen symbol.

## What changed from v0.04

v0.04 explicitly iterated over designer-supplied `B_FAMILY` and `C_FAMILY` arrays.

v0.05 contains no `B_FAMILY`, `C_FAMILY`, `is_b()`, or `is_c()` helper in the runtime source. A dedicated regression test audits that boundary.

Instead the runtime performs four generic steps.

### 1. Candidate role discovery

For every visible symbol `a`, CF-LM examines its learned outgoing relational neighborhood:

```text
Role(a) = { y : Psi[a,y] > epsilon }
```

A candidate role is retained when the neighborhood contains at least three members in this frozen experiment.

That rule discovers exactly two candidate neighborhoods:

```text
R1 -> {B1, B2, B3}
R2 -> {C1, C2, C3}
```

The role identities are therefore reconstructed from persistent relation topology rather than supplied as family arrays.

### 2. Directed schema discovery

For each ordered pair of discovered roles, the runtime measures visible cross-role evidence: the count and total weight of learned `Psi` edges from members of the first role to members of the second.

The strongest directed cross-role pattern is:

```text
{B1,B2,B3} -> {C1,C2,C3}
```

because the visible curriculum contains:

```text
B1 -> C1
B2 -> C2
```

and no reverse-role edges.

The learned schema strength is the mean of the visible cross-role edge weights:

```text
binding_gain = 0.1815085086394108
```

### 3. Member correspondence

Within the discovered source and target roles, pair affinity is derived from cosine overlap between learned incoming `Psi` signatures:

```text
affinity(s,t) = cosine(Psi[:,s], Psi[:,t])
```

Frozen values are:

```text
B1 -> C1 = 0.2849550137339316
B2 -> C2 = 0.2849550137339316
B3 -> C3 = 0.38110399204354856
cross-slot affinities = 0
```

### 4. Teacher-off structural continuation

The discovered-binding mechanism adds the learned structural route during continuation:

```text
x_next[t] += relational_gain
             * binding_gain
             * affinity(s,t)
             * x[s]
```

The direct persistent edge remains untouched.

## Teacher-off result

After training:

```text
Psi[B3,C3] = 0
```

exactly.

The Plain matched arm remains silent on all C targets when probed from `B3`.

The DiscoveredBinding arm produces:

```text
C1 = 0
C2 = 0

C3 step 1 = 0.006917361723235037
C3 step 2 = 0.006917361723235037
C3 step 3 = 0.005188021292426278
```

Thus the teacher-off continuation reaches the structurally matched target while the withheld direct relation remains absent.

## Causal controls

The frozen v0.05 gate includes fourteen tests.

- Plain composition cannot cross the withheld relation.
- Plain and DiscoveredBinding arms share the same trained persistent state.
- The frozen curriculum yields exactly two discovered role neighborhoods.
- Removing all neutral role-anchor experiences removes discovered roles and transfer.
- Keeping role neighborhoods but removing the visible cross-role examples leaves no inferred schema direction, no binding gain, and no transfer.
- Keeping the schema but removing only `A3 -> C3` destroys `B3/C3` correspondence and transfer.
- Replacing only `A3 -> C3` with `A3 -> C2` moves the teacher-off response from `C3` to `C2`.
- Zeroing only `binding_gain` collapses transfer without changing `Psi`, discovered roles, or affinity.
- Zeroing only `affinity[B3,C3]` collapses transfer without changing `Psi`, roles, or schema strength.
- An arbitrary bijective relabeling of all eleven surface symbols preserves the mapped held-out transfer while the mapped direct edge remains zero.
- The runtime source audit confirms no supplied family helper is present.
- Teacher-off probing is nonmutating.
- Repeated runs are deterministic.
- Exact numerical diagnostics are frozen as an independently discoverable regression test.

The arbitrary relabeling control is especially important. The same mechanism survives when the original symbol names and fixed positions are scrambled, which rules out the simple explanation that the runtime is using the literal `B`/`C` names or their original indices.

## Claim ceiling

v0.05 supports this bounded claim:

> Given visible neutral relation anchors and an engineered generic role-discovery rule, CF-LM can derive source/target role sets from persistent relational neighborhoods, infer a directed cross-role schema, preserve member correspondence, and selectively activate a held-out matched target after teacher removal while the direct withheld persistent edge remains zero.

This is stronger than v0.04 because the B/C family arrays are no longer part of the runtime mechanism.

It does **not** establish unrestricted autonomous role discovery.

The following structure is still engineered:

- the teacher provides neutral common-predecessor experiences `R1 -> B*` and `R2 -> C*`;
- the role detector uses a fixed minimum neighborhood size of three;
- role discovery is based on a shared outgoing-neighborhood heuristic;
- the cross-role schema selector and cosine correspondence rule are supplied mechanisms;
- the synthetic curriculum is intentionally constructed so exactly two clean role neighborhoods emerge.

Therefore v0.05 should be described as **experience-derived role assignment under an engineered role-discovery law**, not self-invented ontology or unrestricted concept formation.

It also does not establish:

- discovery of arbitrary latent roles without anchor structure;
- learning the role-discovery law itself;
- invention of unseen symbols;
- natural-language semantics;
- grammar induction;
- unrestricted analogy;
- general abstract reasoning;
- open-domain language competence.

## Next experiment

v0.06 should attack the largest remaining scaffold: the common-predecessor role anchors.

The next question should be:

> Can CF-LM recover role equivalence from distributed higher-order relational motifs when no single symbol explicitly fans out to all members of a role?

That would move the sequence from:

```text
v0.03  abstraction without selective binding
v0.04  selective binding with supplied role sets
v0.05  selective binding with experience-derived anchored role sets
v0.06  distributed latent-role discovery without common role anchors
```

A positive v0.06 would be materially stronger because role membership would have to emerge from repeated relational position across the graph rather than from a single shared predecessor.
